# Plantillas y flujos para canales editoriales y moderados (v1.0)

Cada canal que publica una persona lleva aquí su plantilla, quién publica, cuándo y cómo se revisa.

## #anuncios (publica Javier)
```
📣 **[Título corto]**
Qué cambia: …
Desde cuándo: dd/mm (hora de Madrid)
Qué tienes que hacer tú: … (o «nada»)
```
Flujo: redactar → revisar que no tenga datos personales → publicar → fijar si dura más de una semana.

## Hilo de #lanzamientos (lo crea el bot; el staff añade la valoración)
```
Valoración del staff: 🟢 merece la pena / 🟠 depende de la talla / 🔴 no compensa · motivo en 1 línea
Palabras clave sugeridas para tus alertas: SKU1, SKU2, nombre corto
```
Flujo: el bot crea el hilo → el staff responde con la plantilla en las 24 h siguientes → si cambia algo, el bot lo publica en el mismo hilo.

## #pokémon-expansiones, #tcg-expansiones, #lego, #funko, #mattel, #lanzamientos-otros (foros editoriales)
```
Título del hilo: dd/mm · Nombre (código de expansión o número de set)
Qué es · Fecha y hora de Madrid · Precio oficial · Tiendas con enlace oficial · Valoración 🟢🟠🔴 · Palabras clave
```
Flujo: un hilo por expansión o set; las actualizaciones van dentro del hilo. Para LEGO, la identidad del artículo es el número de set.

## #stock-lanzamientos (editorial, sin fuente oficial)
Indicar siempre la fuente y que es una estimación. Si no hay fuente, no se publica.

## #soporte (tickets privados)
Respuesta inicial: «Hola, soy [nombre] del equipo. Para revisarlo necesito tu usuario de Discord y la fecha del pago (sin datos de tarjeta).»
Flujo: abrir → responder antes de 24 h → si es acceso, ficha del miembro en el panel → «Reintentar sincronización» → cerrar el hilo con el resultado.

## MARKET (solo si lo apruebas)
Anuncio en #vendo-compro (un hilo por anuncio):
```
[VENDO/COMPRO] Modelo · SKU · Talla (EU/UK) · Estado (nuevo/usado) · Precio € · Envío o en mano (ciudad) · Fotos con fecha
```
Moderación: revisión diaria; se borran los anuncios sin precio o sin fotos; la lista negra solo con pruebas; el staff no garantiza la autenticidad.
