# Pagos para reventa: qué mirar (información general)

Esto no es asesoramiento financiero; es una lista de comprobación.
- **Separa** la reventa en una cuenta o tarjeta propia, así es fácil cuadrar el inventario.
- Antes de elegir un banco o una tarjeta, revisa en su web: comisiones por pago en otra divisa (GBP, CHF…), límites diarios de pago y si permite tarjetas virtuales.
- **Tarjetas virtuales**: útiles para compras online. Usa siempre tus datos reales y respeta las normas de cada tienda.
- Guarda los justificantes de compra y de venta; te harán falta para las devoluciones y para la declaración.
