## 📱 PURE - ANÁLISIS DE PRODUCTO

### Lo que sabemos de PURE

Pure es una aplicación de citas para adultos enfocada en encuentros casuales y sin compromisos.

#### Características clave observadas:

**AUTENTICACIÓN**
- Verificación de edad (18+)
- Número de teléfono o email
- Foto selfie verificación

**PERFILES**
- Múltiples fotos (típicamente 5-10)
- Nombre/edad
- Ubicación (distancia, ciudad)
- Bio/descripción
- Preferencias visibles

**DESCUBRIMIENTO**
- Cards con fotos grandes
- Swipe left/right
- Filtros por edad, distancia, género
- Perfiles destacados
- Historial de "vistos"

**INTERACCIONES**
- Like/Dislike
- SuperLike
- Matches
- Chat privado

**SEGURIDAD**
- Bloquear usuarios
- Reportar perfiles
- Verificación de edad
- Moderación de fotos

**MONETIZACIÓN (estimado)**
- GRATIS: experiencia limitada
- PREMIUM: filtros, mensajes ilimitados, visibilidad
- BOOSTS: aumento temporal de visibilidad
- MONEDAS/CRÉDITOS: features adicionales

## 🧮 ALGORITMO DE DISCOVERY - YUIZZ

### Fórmula de Compatibilidad

```
Score = (hashtag_match * 0.40) + (age_range * 0.20) + (distance * 0.20) + (gender_preference * 0.10) + (activity * 0.10)

Donde:
- hashtag_match: % de hashtags que coinciden (0-100)
- age_range: usuario está dentro del rango buscado (0-100)
- distance: inversamente proporcional a distancia (0-100)
- gender_preference: perfil coincide con preferencia (0-100)
- activity: actividad reciente (0-100)
```

### Ejemplo

```
Usuario A busca:
- #Citas #Besos #Sexting #SinCompromiso (4 hashtags)
- Edad: 25-35
- Distancia: ≤25km
- Género: Mujeres

Usuario B (perfil):
- #Citas #Besos #Sexting #Juegos (3/4 coinciden = 75%)
- Edad: 28 (dentro de rango = 100%)
- Distancia: 12km (cercano = 95%)
- Género: Mujer (coincide = 100%)
- Actividad: Visto hace 2h (activo = 90%)

Score = (75% * 0.40) + (100% * 0.20) + (95% * 0.20) + (100% * 0.10) + (90% * 0.10)
      = 30 + 20 + 19 + 10 + 9 = 88 puntos

Usuario B aparecerá con alta prioridad en feed de A
```

### Sistema de Diversidad

- No mostrar siempre los mismos perfiles
- Introducir variedad (nuevos usuarios, perfiles sin match perfecto)
- Ratios:
  - 60% compatibilidad alta (>75)
  - 30% compatibilidad media (50-75)
  - 10% exploración (contenido variado)

## 🏗️ ARQUITECTURA SISTEMA (NUEVO)

### Base de Datos

**Tablas principales:**
- `profiles` (individual/pareja)
- `profile_photos` (máx 3)
- `profile_hashtags` (relación M2M)
- `interactions` (like/pass/superlike)
- `matches` (mutual connections)
- `messages` (chat)
- `user_preferences` (filtros)
- `photo_moderation` (AI flags)
- `reports` (spam/abuse)
- `blocks` (user blocks)
- `premium_subscriptions`
- `user_activity_log`

### API Endpoints (NEW)

